## 📌 Overview

An interactive 3D word cloud and semantic tag visualization engine built with vanilla **JavaScript** and **HTML5 Canvas**. Renders words in dynamic spherical orbits responding to cursor movements.

---

## ✨ Key Features

- **Interactive 3D Orbit:** Words rotate continuously on a virtual 3D sphere influenced by mouse velocity.
- **Dynamic Scaling:** Tags scale in size and opacity based on their virtual z-axis depth position.
- **Custom Vocabulary:** Easily configurable word arrays, weights, and color schemes.
- **Lightweight & Performant:** 60fps animation loop optimized for smooth browser execution.

---

## 💻 Tech Stack & Architecture

- **Graphics & Engine:** HTML5 Canvas API, 3D Trigonometric Math (Sin/Cos Orbit)
- **Logic:** Vanilla JavaScript RequestAnimationFrame
